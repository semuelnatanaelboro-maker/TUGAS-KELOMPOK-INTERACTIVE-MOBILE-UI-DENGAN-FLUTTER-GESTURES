# Smart Solar Monitoring Dashboard (SDG 7)

Aplikasi mobile interaktif menggunakan Flutter untuk memantau penggunaan energi terbarukan (panel surya).

## Fitur & Gesture Interaktif
- **Swipe / Horizontal Drag**: Menghilangkan (dismiss) kartu notifikasi peringatan.
- **Double Tap**: Menyimpan (bookmark) kartu indikator daya ke daftar favorit.
- **Scale / Pinch**: Memperbesar dan memperkecil (zoom in/out) tampilan grafik output inverter secara real-time.
